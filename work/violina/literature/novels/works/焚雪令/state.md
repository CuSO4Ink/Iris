# 《焚雪令》·状态与事件

## CurrentState

### 时间与地点

- 时间：停战第七年，早春，郁青梧抵关当夜。
- 地点：雍国北境折雪关；郁青梧一行暂居外门瓮城。

### 人物

- 崔照霜：以遇险旅人的名义准许郁青梧一行在瓮城留宿一夜，尚未允许她们进入内关或通过烬道；收回七年前遗失的短刀。她确认北坡新出现裂雪风险，已命人准备天亮后勘查。
- 郁青梧：带领十二人抵关，其中一人发热、两人有轻度冻伤；长兵器与弓已按条件封存在外门值房。她公开请求借烬道三日，烧掉朔国通行符，不再以朔国使令身份要求开关；真正目的尚未完整说明。
- 邱素：折雪关老卒，负责外门点验与夜间轮值；对收容武装行旅有疑虑，但按正式程序执行并保留点验记录。

### 关系

- 崔照霜—郁青梧：七年后重逢。警戒和旧账仍在；郁青梧主动恢复私人接触，崔照霜只确认了留宿边界，没有给予通行承诺。

### 开放线程

- 郁青梧为何必须借烬道三日。
- 她为何保存并此时归还崔照霜的短刀。
- 她当年没有完成追击的真实原因。
- 北坡裂雪是否会封死烬道或危及关城。
- 崔照霜收容十二名无籍旧敌后可能承担的制度后果。

### 当前主脉络

- 在融雪风险与越权代价同时逼近时，崔照霜必须决定是否、以及为谁开放烬道。

### EV-0001 · 关下重逢

- **时间**：停战第七年早春，自午后至当夜。
- **地点**：折雪关外门、瓮城与外墙。
- **前因**：折雪关依停战约封闭烬道；崔照霜与郁青梧七年未见；郁青梧带十二人的无籍行旅队在融雪期抵关。
- **参与者**：崔照霜、郁青梧、邱素、折雪关守卒、郁青梧的十一名同行者。
- **各方目标**：崔照霜要守住开关权限并避免让遇险者死在门外；郁青梧要让队伍获得当夜庇护，并争取三日内使用烬道；邱素要保证收容程序不使外门失守。
- **约束与筹码**：郁青梧持有朔国通行符，但该符不能自动迫使雍关开门；她的一名同伴发热、两人冻伤，粮食只够两日；春雪将至；崔照霜可依旧例收容遇险旅人，却无权准许成建制武装越过内关。
- **实际行动**：郁青梧在关下烧掉通行符，表明不以朔国使令身份入关；她把崔照霜七年前遗失的短刀插在雪中，请借烬道三日。崔照霜逐项询问人数、伤情、武器、粮食与追兵，拒绝立即开放烬道，但提出封存长兵器、点验人员、只入瓮城一夜的条件。郁青梧接受，崔照霜下令移开拒马并开放外门小扉。夜里，郁青梧借瓮城旧阶攀上外墙查看北坡，被巡卒发现后没有继续越过警戒线；崔照霜亲自到场。两人在墙头谈及七年前的追击和当前请求，仍未互相说明全部理由。郁青梧指出北坡雪层的异常，崔照霜核实后下令天亮勘查。
- **结果**：十二人获得一夜庇护，折雪关内门仍闭；通行请求未决。崔照霜取回短刀，并第一次确认郁青梧主动来找的是她而不只是关门职位。北坡裂雪成为下一步必须处理的现实压力。
- **状态增量**：
  - 世界：春雪将至；北坡出现可能滑塌的新裂线。
  - 崔照霜认知：知道郁青梧已脱离朔国军籍、保留短刀七年、带队请求借道；不知道其完整任务与当年放弃追击的全部原因。
  - 郁青梧认知：确认崔照霜仍会在权限内为具体人命承担风险，也确认她不会因旧情或旧债直接开关。
  - 关系：由断绝往来的旧敌变为暂时处于同一关城、可以直接谈判的双方；信任未建立。
  - 行动空间：郁青梧一行可在瓮城休整至天亮；崔照霜将在勘查北坡后重新处理通行请求。
