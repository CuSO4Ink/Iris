# Prose Generation Guard

> 固定小说的初稿后拒绝测试与返修规范。事件事实来自 `story-engine.md`；本文件不进入首稿上下文，也不作为逐项兑现的生成提示。审校纠错，但不把有限注意留下的纹理统一磨平。

## 文学边界

- **事实约束表达**：EventRecord 决定发生过什么，不决定人物怎样经历、何时理解或语言产生什么余韵。正文不得改写已提交事件，也不得把人物误判升级为世界真相；但逐项复述事实或给结论换上漂亮说法，同样不构成文学经验。
- **经验不可约**：关键选择、认识变化和关系转折不能只靠抽象结论或可移植比喻命名。语言须让变化经过人物特有的感知区分、身体、动作、时间感、句法与未完成解释；若朴素概括保留了原段几乎全部作用，原段仍主要在传递信息。普通交代与过渡不受此要求。
- **有限注意**：正文沿当前主脉络顺写，不从全书上空为每段分派任务。外部事件持续经过限知人物的注意、感官、身体、联想、判断、误读与欲望，形成连续内在因果；清冷和克制不等于心理空白。人物可以执着小事、漏掉显眼信息，让感受悬而未决。
- **路径残余**：有限注意、知识边界、情绪惯性、语言偏好与现场过程会留下因果上非必要的停留、近似、过量或空缺。它不接受逐项功能验收，也不要求每一处都能解释清楚“为何想到这里”；只要没有破坏事实、人物边界和主脉络，局部无意义本身可以成立。
- **人物与他者**：履历须变成当前反应和私人行为规则。爱情双方始终保有各自欲望、伦理、边界与行动线；关系间歇显影，不按固定心理链条连续供给。
- **上游归因**：关键行动、台词或心理若无法追溯到人物状态与事件因果，退回故事引擎重跑，不靠补解释、换词或金句遮住。

## 噪声优先级

噪声不是几处废话或闲笔，而是全文在句子、交谈、场景和章节尺度上自然出现的不均匀：有的地方因兴趣或惯性多走一段，有的预期信息暂时漏掉，有的措辞只达到近似，有的支线冒头后没有承担任务。它低于事实与人物连续性，高于简洁、漂亮、功能密度和结构闭合；两者冲突时，优先保留不均匀。

噪声只看分布，不做配额。不得规定每章必须出现几次废话、失误、无用器物或不回收细节，也不得在 `voice.md` 预列具体器物和“遇到 X 就做 Y”的反应，再由正文逐项兑现。那不是有限写作留下的残余，而是对残余的统筹表演。

经验不可约也不做配额。不是每个物件都要同时压住事实、身体、历史和感情，不是每句话都要留下多义余韵；路径残余可以什么都不象征。若全文句句承重、处处无法概括，文学性本身已经成为另一种高功能密度。

## 六项校准

1. **偏视**：篇幅追随人物真正看重的东西，不按情节重要性平均分配。她的词汇、可作出的感知区分和注意顺序决定世界怎样进入文字；不是先得到通用场景，再覆盖一层职业术语。具体感来自她能感到的痕迹、动作与环境，抽象判断和比喻也须受这一边界限制。
2. **内生**：人物从自身欲望、身体习惯、私人规则和处境生成反应；事物首先保有自己的重量、用途、阻力和现实后果，关系含义从人物持续处理它的过程生长，不由作者预先指定象征。若具体反应破坏抒情、恐怖、浪漫或庄严气氛，优先保留人物，不替类型腔维持漂亮统一。
3. **声纹**：人物拥有不同句长、词汇、话量、理解速度、错误重点和回避方式；作品本身也有有限词域、知识半径与惯用联想。句法和节奏承受人物此刻整理经验的难易，不是固定签名。专业精确只来自人物确有的知识和现场证据，其他感受允许近似、重复、绕远，不临时调用百科式最优词。普通人物默认说自然完整的话，会解释、补充、绕行，也会随情绪增加话量；短句主要留给命令、冲击和真正失语。“惜字如金”只用于确实以此为核心的少数角色。声纹描述边界，不要求每场展示全部特征。
4. **余量**：信息和功能密度须起伏。谈话可以越过任务点再滑出几句，注意可以在小事上停得过久，某处写得比结构需要更多，另一些预期信息可以暂时空缺；情节不受益也能留下，不为每一处建立理由。对白可以不配动作，人物可以静止；现场余物可以永不回收，梦与受扰意识可以按联想跳接。禁止按数量插入废话、无用器物、随机失误或故意用错词。
5. **振幅**：情绪先于整理，并改变话量、动作、判断、攻击性、依赖、求助与恢复速度。压力结束后仍留余震，不把害怕统一写成短句、停顿、手抖和压低声音。情绪高点的话量须落成直接台词，不得用“骂了几句”“解释了一番”等概括替代。
6. **克制**：尊重认识发生的时间，不替人物揭穿尚未认出的防御，也不在细节抵达含义后追加总结。一个动作可以同时留下数种有具体根据、尚未裁定的感受；证据与职业判断可以准确，普通感受允许近似、游移和没有落点。可无损移植到其他作品的漂亮话优先删去或退回具体感知。

## 三类失败证据

以下只用于诊断，不是另一套生成规则：

- **模板接管人物**：清单复刻、低温同声、全员最优、同化式爱情、关系卖点按节点验收，或稳定人格被写成固定反应。
- **叙述者接管感知**：监控式限知、过度精确、解释收尾、用可移植比喻重述抽象结论、句内反复“先否定再给锋利答案”，或人物总能准确识别自己的感情与防御。
- **编排暴露方法**：周密腔把前提、例外、责任、目的和方案一次说全，像在交付答复；其他症状包括人物一开口便摆弄器物、配角固定承担笑点或递线索、所有物件进入同一因果网，以及每个具体细节都同时承担事实、人物历史、关系和余韵。反过来按配额散布废话、失误和无用物，或让正文准确复现后台列出的具体闲笔与条件反应，也是统筹痕迹。相关连接词不是禁词，惊慌中的反复改口应保留；不要误伤由身体、欲望与认知偏执自然生成的重复行为。

## 初稿后双审

1. 首稿写完后再读取本文件，并读取已提交事件、主受可见信息、相关当前状态、声纹与必要近期正文。
2. 只对关键选择、认识变化和关系转折做静默概括：若概括保留了原段几乎全部阅读作用，退回人物的注意、身体、时间和认识过程重构，不靠增加比喻或感官清单补救。
3. 再看全文实际形成了怎样的不均匀分布：哪里过写、哪里漏写、哪里措辞近似、哪里收束过早或滑出过远。不要逐条替它们寻找理由，也不要把概括损失推广成逐句指标。
4. 只删除制造事实错误、破坏人物边界、持续截断主脉络或明显按配额伪造的部分，不把全篇修成同一精度与密度。若闲笔、动作和反应准确复现 `voice.md` 的具体示例或条件公式，退回作品后台清除预排后重写，不在正文上伪装自然。
5. 分开审校：事实审校检查连续性、视角与泄密；文学审校检查经验是否不可约、人物来源、声纹、余量、振幅、克制及三类失败证据。失败按来源退回事件层或表现层。

静默复查只问：EventRecord 是否被逐项转写；关键变化能否被无损概括；全文是否真的有过量、遗漏、近似和未回收造成的幅度；事物是否先真实存在而非充当象征；人物声音与情绪是否真正不同；后台是否预写了正文待兑现的噪声；审校是否制造了句句承重或均匀编排；文学修辞是否污染事实。默认只交付最终文本，除非用户要求分析。
