# Story Engine

> 固定小说唯一的故事运行规范。互动文字在 `../interactive-fiction/` 独立定义；本文件不承担玩家输入与在线提交协议。

## 一、权威与提交

人物与事件是叙事基元，状态增量是最小写入单位。

```text
StoryAuthority = Canon + CommittedEvents
CurrentState   = Materialize(StoryAuthority)

CurrentState
= World + Characters + Relationships + OpenThreads
```

- **Canon**：世界规则、人物稳定核心、关系硬边界、视角与结局硬锚点；普通事件不得覆盖。
- **CommittedEvents**：按顺序追加的历史唯一真源。每条事件记录前因、参与者、实际行动、结果，以及对世界、人物认知、关系和线程造成的增量；旧事件只追加勘误。
- **CurrentState**：截至最新事件的可重建视图，不拥有独立历史权威。

同一事实只设一个权威落点。稳定事实写入 Canon，历史事实写入事件账本，当前状态只保留最新值并指向来源事件。隐藏大纲与候选未来属于规划层；声纹、近期正文与读者文本属于表现层；二者均不能修改事实或进入人物认知。

文件模式固定为：

- `stable-setting.md`：Canon。
- `state.md`：上半部 CurrentState，下半部只追加 CommittedEvents。
- `hidden-outline.md`：真相、长期压力、可废弃候选、篇幅与阶段边界，不预排段落功能。
- `voice.md`：人物声纹，以及作品有限词域、知识半径、可作出的感知区分、句法范围和特有文学约束；它不是职业术语表，只描述范围与不可达之处，不预告当前场景会出现的器物、动作和反应。
- `<作品名>.txt`：唯一读者正文。

一次生产先在事件层验证并提交 EventRecord，再刷新 CurrentState；写入 `state.md` 时必须先向下半部追加事件，再由 Canon 与全部已提交事件刷新上半部状态。中断、写入失败或上下不一致时，从 Canon 与事件账本重建 CurrentState，不重写无关历史。表现层只读取已提交结果和视角可见信息；EventRecord 约束事实，不规定正文的顺序、篇幅、注意权重或最终含义。初稿完成后才按 `prose-generation-guard.md` 审校。修辞、隐喻和人物误判不得反向污染事实。需要数据库时优先使用 SQLite 的稳定设定、事件与状态物化表，不提前建设图数据库或独立向量库。

## 二、人物与事件

### 人物状态

- **稳定层**：气质、价值核心、长期欲望、能力边界、身体习惯、私人行为倾向与声纹。它记录概率范围和持续压力，不把人格写成“遇到 X 必定做 Y”的反应公式；生理限制与世界硬规则除外。
- **可变层**：当前目标、身心状态、资源、地位、信念、防御、关系和事件余留。
- **认知层**：已知、误解、怀疑、隐瞒、注意重点和不可见信息。
- **社会层**：身份、权力、资历、共同历史、可用程序及越权代价。
- **行动层**：她此刻认为能做什么、愿付什么代价、最想推进或阻止什么。

这些是运行维度，不对应多套账本。人物只按局部状态行动，不执行作者交给事件的功能；稳定字段可以整章潜伏，不要求轮流显影。私人行为倾向应从身体、欲望、警戒、习惯与价值生长，在新处境中变形，而不是把后台示例逐项搬进正文；人物可以为了自己的小事错过显眼威胁，也可以破坏作者预备的类型气氛，只要不是强行降智。制度、身份、权力与资历必须真实限制表达方式和行动后果，但权威不等于全员沉默；异议应从正式劝谏、谨慎试探、拒绝或拖延、私下议论，或具备资格的上位者等现实通道发生，并承担相应代价。

### 事件

- 每一生产段先确定当前最有牵引力的一条主脉络：它来自尚未解决的欲望、压力、问题或既有后果。其他线索、人物弧和关系弧不按轮次并列推进，只有实际撞入当前处境时才进入。
- 来源可以是人物行动、旧伏笔、连环后果、镜头外主体、制度与环境变化，或符合世界的偶然。
- 事件包含触发、参与者、时空、筹码、约束及各方不同的未决目标。
- 伏笔是已存在于状态中的因果潜势，不是等待按时触发的道具。
- 只有确实改变选择、结果或状态的器物进入事件因果；正文中的现场余物不自动成为线索、人物标签或未来伏笔。

### 参考输入

参考作品、文案或桥段先拆为：表层素材、关系机制、情感回报、可变外壳。默认只继承关系机制与情感回报；除非用户明确指定，不复制人物职能、世界设定、事件顺序和标志性桥段。若仍能从新作品反推出参考剧情骨架，退回重做。

## 三、检索与事件循环

每次只装载最小充分状态：

```text
项目硬约束与世界规则
→ 当前事件和视角边界
→ 直接参与者、相关关系、认知与开放线程
→ 明确前因事件
→ 少量近期事件与必要原文
→ 语义相似历史作为补充
```

明确 ID、因果链接、参与者与开放线程优先于语义相似度。默认读取结构化事件摘要；只有恢复声纹、动作回声、旧承诺或未显式链接的主题关联时才读原文或使用 RAG。现有索引与全文检索足够时不增加向量层，向量只补充无明确链接的语义召回。隐藏规划只限定方向、边界并检查死路，不得进入人物认知或逐段分派功能。

共享事件循环：

1. **触发**：状态满足人物行动、伏笔、后果、世界变化或偶然条件。
2. **激活**：只载入能感知、影响或被影响的主体；镜头外人物仍可行动。
3. **局部感知**：每人按位置、能力、身体、注意和偏见解释现场。
4. **独立决策**：每人只处理自己真正关心的目标；合作也来自各自理由。
5. **行动碰撞**：行动彼此促进、阻碍、误导、放大或抵消，制度、资源、身体与时间持续施压。
6. **扰动介入**：误听、迟到、失误、改意、琐事、故障和世界内偶然可以改变路径，也可以只消耗时间或注意；不得替作者解围，也不强制升级为伏笔。
7. **结果生成**：产生一个或多个因果有效的结果，可以无人完全满意。
8. **有限择向**：先淘汰违反人物、认知、连续性和世界规则的结果，再优先选择最贴近当前主脉络、局部因果最强且能留下真实后果的方向；长期规划只排除死路或在难分时定向。
9. **提交回写**：更新得失、认知、关系、信念、防御、行动空间、世界与开放线程。

每个相关人物都要结算，但不要求每场改变性格，也不要求一章同时推进案件、真相、秘密与关系。部分结果可以不完整、不漂亮，只要后果真实进入历史。

## 四、固定长篇

### 完本规划

- 规划同时维护事件主线、人物弧与关系弧的长期方向，锁定真相、外部压力、阶段终点和结局边界；它们不构成逐章评分表，也不替人物预选唯一行动。
- 人物弧区分稳定核心与可变信念、防御和关系策略；经历必须改变后续选择。
- 爱情从进入彼此视野后积累，但关系信号可以稀疏、延迟或暂时缺席；双方始终保有独立行动线。
- 开写前确定总字数、卷级压力、人物与关系阶段及当前批次位置；未来章节只保留可调整职责。篇幅预算用于给选择、后果和余震留下场景空间，不是灌水指标。

### 有限择向

统筹退到边界层：它维护全书真相、终点、篇幅、连续性和不可逆后果，不要求当前事件同时证明人物弧、关系弧、主题与伏笔。实际选择从主脉络出发，只使用有限前瞻；不必在每个节拍生成完整候选菜单，也不因某条路径能服务更多目标便自动选它。

当前因果、人物选择和后续余震相近时，才以人物弧、关系弧、主题、全书节奏或旧伏笔回声定向。最激烈、最狗血、扣合最整齐或单章功能最多的结果都不自动胜出。允许没有说准的话、局部写过头或交代不足、不会回收的现场余物、延迟生效的线索和不形成漂亮闭环的中间状态。单个路径残余不接受用途验收或强制溯源；只在全文层面排除与人物、词域和现场长期无关的机械乱入。若候选都像在展示结构能力，减少本章任务；若只能靠人物失真变精彩，退回触发、参与者、信息差、筹码与世界压力重跑。

### 生产闭环

1. 先提供无剧透作品入口：书名、故事性正文文案、关系标识、标签和一句话简介。文案从主受当下处境起步，让另一名女性通过行动进入，以少数具体瞬间建立关系钩子，停在尚未解决的张力上；不泄露真相，不写成大纲摘要或第一章缩写。
2. 入选后建立稳定设定、状态、隐藏规划、篇幅预算、声纹和读者 TXT。
3. 事件阶段执行“主脉络追索—最小检索—局部运行—有限择向—提交回写”，先使本章事实成为已提交历史。
4. 首稿阶段只读取本章 EventRecord、主受当前切片、`voice.md` 与必要近期正文；不读取关系池、隐藏规划或文学守门。`voice.md` 只限制语言与知识边界，不提供本章待兑现的人格动作；EventRecord 不按字段逐项转写，已提交事实可以依视角被压缩、延迟或略过。沿视角注意顺写，允许局部联想、停留与近似措辞自然漫出；性格字段和关系信号可以整章不出现，不反向补齐，也不故意制造瑕疵。初稿完成后再加载文学守门，执行事实与文学双审。
5. 因果或人物问题退回事件层，文学问题退回表现层，不在句面补结构洞。
6. 读者侧只维护一个 UTF-8 TXT，含书名、卷章名和正文，不含后台、Markdown 或剧透。

## 五、运行审校

- 是否有人为了预设结果违背当前动机、认知、能力或制度位置。
- 每名参与者是否在做自己关心的事，配角是否被固定成说明者、笑点、缓压阀或递线索的人。
- 制度、身份与资历是否产生真实约束，服从与异议是否通过各自可用的现实通道表达并承担代价。
- 镜头外主体与世界力量是否持续运行，结果是否来自行动碰撞。
- 事件得失是否完整回写，关键经历是否改变后续判断与选择。
- 单章是否承载过多揭示与关系节点，器物、线索和数字是否被迫汇入同一因果网。
- 是否确有一条当前主脉络，有限择向是否优先服从局部因果与真实余震，而非同时优化全书目标或选择最整齐的结果。
- 正文是否把 EventRecord 逐项换成场景与对白，还是按视角重新分配了顺序、篇幅、遮蔽和经验重量。
- 检索是否只加载最小充分状态，并隔离事实、人物认知、规划与文学表现。
