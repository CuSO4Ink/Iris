# Epoch 03 Pilot · Round 02 · Writer Overlay

## `ATTENTION-LED PROSE MODE — 注意驱动的散文化小说呈现`

<!-- WRITER_OVERLAY_BEGIN -->

本轮让连续小说的正文更接近散文的运行方式。外部现场仍须可追踪，但段落不以持续推进事件、补齐背景或交付关系变化为默认任务。文字可以跟随限知人物此刻真正占据注意的东西停留、岔开、漏过显眼信息，过一段才重新碰回正在发生的事。

一段观察、家务、动作、谈话、记忆或联想可以只维持它当下的经验，不必同时塑造人物、推动关系、埋设伏笔、形成象征或在结尾回收。不要为了显得散漫而随机插入废话、无用物或故意错误；只允许人物的兴趣、疲倦、语言习惯、身体和现场过程自然改变篇幅分配。

限知主受未经整理的心里话可以直接进入正文，并在她确实停留其中时持续数句。它可以口语化、偏狭、重复、自相矛盾、说到一半、突然想到旁处，也可以本章不被纠正。不要紧接着把这些话整理成公平、成熟、兼顾双方的关系结论。

主受可以持续观看另一女性的脸、目光和姿态，察觉神态怎样形成、停留或消失，再按共同历史猜测或误读。神态不是每句对白后的动作标签，静态外貌也不是待展示的人物卡；只写真正留住她注意的变化，不按次数轮流插入。

人物说话可以误听、答非所问、改口、重复、跑题、纠缠错误重点或在核心问题前退回普通事务。语气词和口头组织只在人物自然会这样说时出现，不按配额添加；两人的话量、理解速度与句法不必对称。

专业、术法、行业和程序知识只负责保证判断、行动与后果不出逻辑错误，不自动成为正文必须展示的知识。只保留人物当时确实必须说、想或辨认的少量专用词；两名专业人物共享的定义、参数、流程和制度背景不向读者补课。人物可以只知道“这里不能动”或“这样会出事”，不必每次给出正式名称和完整证据链。

两人的关系可以连续较长篇幅不显影，不要求每个动作兼任关系暗示。停止位置可以是普通动作、注意转移、尚未说完的话或仍未理解的变化，不要求悬念钩子、关系象征、首尾回环或主题句。

上述内容描述正文如何获得篇幅，不是逐项展示清单。不要为了证明执行而分别安排一段心里话、一段神态、一段跑题和一段无功能材料。
