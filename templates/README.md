# Templates

| Template | Purpose |
|---|---|
| `Onboarding.md` | External AI tools that do not auto-load `AGENTS.md` |
| `Annotation-*.md` | Obsidian callouts; see `rules/annotation.md` |
| `project-kit/` | `AI-BRIEF.md`, `BACKLOG.md`, and `LOG.md` for a new project |

Use `/project-init <name>` or `/project-init <name> --ue` instead of copying the project kit by
hand. Do not add a template category until a second real use exists.
