# 图形 TA 知识体系

> 用途：定义图形方向技术美术必须熟练掌握的知识体系全景，以及「熟练掌握」的
> 判定标准。内容是行业通用的岗位要求，不与任何个人项目或证据绑定；个人自评、
> 证据核对与盲区处置由 `TECH-STACK-REVIEW-CARDS.md` 和正本承担，本文件只提供
> 「应该掌握什么、掌握到什么程度」的标尺。
> 创建：2026-08-29（review 项目）；同日重构为通用岗位体系（去除个人证据映射）。

## 熟练深度分级

| 级别 | 含义 | 判定 |
| --- | --- | --- |
| L1 认知 | 知道是什么、用在哪 | 能概述用途与适用场景 |
| L2 理解 | 懂原理、权衡、典型坑 | 能回答「为什么选 A 不选 B」 |
| L3 复现 | 能手写核心公式/代码/节点 | 白板可推导，断网可重建 |
| L4 精通 | 能落地、量化、定方案 | 独立交付过并能量化收益，能评审他人方案 |

图形 TA 的核心域要求 L3–L4，支撑域 L2，协作域 L1–L2。

## 一、基础科学层

### 1. 数学基础（要求 L3）
- 核心节点：线性代数（向量、矩阵、齐次坐标、变换链、基底变换）；四元数与旋转
  插值；微分几何直觉（法线、切线、曲率、梯度）；插值与曲线（lerp、smoothstep、
  Hermite、贝塞尔、样条）；噪声族（Perlin、Simplex、Worley、fBm、Turbulence、
  Domain Warp）；概率统计（分布、期望方差、P50/P95、蒙特卡洛思想）；数值常识
  （浮点精度、积分步长、稳定性、误差累积）。
- 熟练掌握标准：白板推导 MVP 变换链与法线矩阵；手推双线性/三线性采样；从几何
  意义解释点积与叉积；给定视觉需求能选噪声类型并完成参数化。

### 2. GPU 体系结构与并行编程（要求 L3）
- 核心节点：SIMT 与 wave/warp 调度、分支分歧；内存层级（寄存器、共享内存、
  L1/L2、显存）与合并访存、bank conflict；occupancy 与寄存器/共享内存权衡；
  roofline 模型（带宽受限 vs 算力受限）；原子操作与竞争串行化；并行原语
  （reduce、prefix scan、sort、compact、histogram）；compute shader 线程模型；
  wave 内操作（shuffle/ballot）；异步计算与多队列。
- 熟练掌握标准：用 roofline 判断 kernel 瓶颈类别并给出两条以上优化路径；能手写
  prefix scan 与分桶 compact；解释原子竞争的根因与局部聚合缓解。

### 3. 颜色科学与 HDR 管线（要求 L2）
- 核心节点：色度学基础（光谱、三刺激值、色域 Rec.709/2020）；线性空间与
  transfer function（sRGB/gamma）；白平衡与色温；HDR 存储（half float/EXR）；
  tonemapping 曲线族（Reinhard、ACES、AgX 概念）；LUT（1D/3D）生成与应用；
  dithering 与色带；感知均匀色彩空间常识（Lab/OKLab）。
- 熟练掌握标准：完整讲清「贴图解码 → 线性光照 → tonemap → 显示」全链路中每步
  的空间与格式；能定位 gamma 错误、色带等常见链路问题。

## 二、渲染原理层

### 4. 图形管线与图形 API（要求 L3）
- 核心节点：光栅化管线全阶段（IA、VS、HS/DS、GS、光栅化、PS、OM）及各阶段可
  编程能力；mesh/amplification shader 管线；光线追踪管线概念（BLAS/TLAS/SBT、
  raygen/closest-hit/miss）；延迟、前向、Forward+、clustered shading 的取舍；
  显式 API 模型（command queue/allocator/list、PSO、root signature/descriptor
  heap、资源状态与 barrier、bindless）；同步原语（fence/semaphore）；帧并行与
  交换链 present 模型。
- 熟练掌握标准：画出延迟与前向两条数据流并说明半透明、MSAA 在各自下的处理；
  手写一次 draw 在 D3D12 下的完整提交序列；解释 barrier 漏配导致花屏的根因。

### 5. 光照、阴影与全局光照（要求 L2–L3）
- 核心节点：辐射度量基本量（radiance/irradiance）与渲染方程结构；解析光源
  （方向、点、聚、面光）；IBL 与 split-sum/预过滤环境图；阴影族（Shadow Map、
  bias 与 acne/peter-panning、PCF/PCSS、CSM、VSM/EVSM、SDF 阴影、光线追踪
  阴影）；AO 族（SSAO/HBAO/GTAO/DFAO/RTAO）；GI 方案族（烘焙 lightmap/probe、
  irradiance volume、LPV、SSGI、Lumen SW/HW、RTGI、路径追踪参考）与场景选型；
  多次弹射近似思路。
- 熟练掌握标准：按场景类型（开放世界/室内/全动态/全静态）选型 GI 与阴影组合
  并说清代价；解释 bias 系问题根因与 PCSS 半影原理。

### 6. 材质与着色模型（要求 L4）
- 核心节点：BRDF/BTDF/BSSRDF 概念系；微表面理论（D 分布 GGX/Beckmann、G 几何
  遮蔽 Smith、F 菲涅尔 Schlick 与精确式、能量守恒与补偿）；经典模型
  （Lambert、Phong/Blinn-Phong、Cook-Torrance、Oren-Nayar）；各向异性
  （Kajiya-Kai、Marschner 概念）；皮肤 SSS 近似（曲率图/厚度图/预积分）、
  眼睛、布料 sheen、ClearCoat、薄透明；NPR 体系（Ramp/Curve、MatCap、SDF
  脸部阴影、描边两族、笔触与纸感）；材质分层与实例化参数；透明排序与 OIT；
  纹理压缩格式（BC1–7、ASTC）与各通道选材；虚拟纹理与流送。
- 熟练掌握标准：默写 Cook-Torrance 并说明每项物理意义；为指定风格（写实、
  PBR+Toon 混合、水彩等）给出完整材质配方与成本分析。

### 7. 抗锯齿、后处理与图像重建（要求 L2–L3）
- 核心节点：走样来源（几何走样、着色走样、时域走样）；MSAA/FXAA/SMAA/TAA
  原理与代价；时域上采样（重投影、历史拒绝、ghosting；TSR/DLSS/FSR/XeSS
  概念）；运动矢量生成；后处理链（bloom、DOF、motion blur、SSR、vignette、
  grain、chromatic aberration）的正确顺序与 HDR 位置；屏幕空间技术的通用失效
  边界。
- 熟练掌握标准：解释 TAA ghosting/shimmer 根因与缓解手段；为项目排一条顺序
  正确的后处理链并说明每步所在的颜色空间与分辨率。

### 8. 体积渲染（要求 L3–L4）
- 核心节点：参与介质光学（吸收、散射、发射；Beer-Lambert 与光学深度）；相函数
  （Rayleigh、Mie、Henyey-Greenstein、双瓣）；单次/多次散射与近似（powder、
  能量补偿）；raymarching 与跳步优化（空域裁剪、保守密度、自适应步长）；froxel
  体积雾；体积材质与云配方（噪声造型、侵蚀、天气图、时间重投影）；稀疏体积
  数据结构（VDB/NanoVDB、HDDA 遍历、SVT 分页）；体积光照与光程烘焙。
- 熟练掌握标准：从 Beer-Lambert 推出离散 raymarch 累积公式；为云、雾、烟各给
  一套质量—性能方案并说明体积光照的代价模型。

## 三、引擎与内容层

### 9. 引擎架构与渲染扩展（要求 L3–L4）
- 核心节点：引擎线程模型（游戏/渲染/RHI 线程）与场景代理数据隔离；渲染图
  （RDG 类声明式组织）的自动资源池与 barrier；shader 系统（global shader、材质
  编译、排列组合控制、DDC）；渲染扩展点（SceneViewExtension 类钩子、自定义
  pass 注入）；对象系统/反射/GC；模块与构建系统；资产链路（导入、cook、打包、
  流送）；插件化组织与版本升级迁移。
- 熟练掌握标准：完整讲出并实际做过「自定义渲染 feature 接入引擎」全链路；能
  处理引擎版本升级时的渲染扩展迁移。

### 10. 可见性、LOD 与渲染组织（要求 L3）
- 核心节点：视锥剔除与遮挡剔除（HiZ、软件光栅遮挡、GPU-driven culling）；LOD
  策略（静态 LOD、HLOD、几何简化、impostor）；虚拟化几何概念（cluster 化、
  软硬件光栅混合）；draw call 优化（合批、实例化、MultiDrawIndirect）；场景
  分块与流送；渲染状态切换与排序成本；overdraw 模型与控制。
- 熟练掌握标准：给定帧时间分解，能指出渲染组织层面的三个优化点并预估收益
  量级。

### 11. 粒子与物理模拟（要求 L3–L4）
- 核心节点：粒子系统架构（system/emitter/module、属性驱动、事件）；CPU vs GPU
  模拟与确定性要求；自定义迭代阶段与外部资源读写；数据接口（网格、RT、邻域、
  跨发射器读取）；实时流体方法族（SPH、PBF、FLIP 概念与取舍）；约束投影
  （PBD/XPBD）；涡度、粘性、表面张力细节；群体模拟（boids、流场、人群）；
  布料与破碎常识；粒子渲染（billboard、拉伸板、软粒子、光照粒子）。
- 熟练掌握标准：写出 GPU 邻域模拟的完整数据流；按预算（粒子数、迭代数、网格
  分辨率）分解成本模型并给出降级方案。

### 12. 几何处理与程序化内容（要求 L3）
- 核心节点：网格表示（拓扑、法线、切线、UV、顶点属性）；SDF 构建、法线差分、
  布尔与平滑操作；等值面提取（Marching Cubes 查表与歧义、Dual Contouring
  概念）；重拓扑与简化；程序化生成范式（PCG 图：采样/过滤/变换/生成；L-system；
  WFC 概念）；DCC 程序化范式（Houdini SOP/VEX/求解器/烘焙导出）；地形系统
  （高度图、层权重、LOD）；实例化输出与剔除粒度。
- 熟练掌握标准：手写 Marching Cubes 单个 case 的推导；为一张地表设计分层
  PCG 方案并说明结果验证方法。

### 13. 动画、绑定与角色渲染（要求 L2）
- 核心节点：骨骼与蒙皮（LBS、DQS、体积保持）；blendshape/morph target；IK
  （两骨、CCD、FABRIK）与约束；动画混合、状态机与重定向；顶点动画烘焙
  （VAT/RBD VAT）；毛发渲染（strand/card 与 Kajiya-Kai）；角色特化材质（眼球、
  牙齿）；布料模拟常识。
- 熟练掌握标准：能诊断蒙皮瑕疵（关节塌陷、糖纸效应）并给出修法；VAT 烘焙到
  引擎播放的链路达到 L3。

### 14. 神经渲染与新表示（要求 L2–L3）
- 核心节点：可微渲染概念；NeRF 族（体渲染、位置编码、蒸馏）；3DGS（参数集、
  投影、α 混合、训练与 densify/prune）；动态/4D 扩展概念；特征网格、三平面与
  小 MLP 蒸馏；神经材质与神经纹理压缩概念；质量评估指标（PSNR/SSIM/LPIPS）；
  与经典表示的适用边界（何时不应该用）。
- 熟练掌握标准：讲清 3DGS 训练与渲染两条链路；能评估一个神经表示的落地成本
  （显存、训练时间、引擎接入方式）。

## 四、生产与协作层

### 15. 性能工程与图形调试（要求 L4）
- 核心节点：测量方法学（口径分层：pass/feature/帧/进程；统计量 P50/P95；控制
  变量、冷进程、固定上下文）；工具链（引擎内置 stat/ProfileGPU/Insights、
  RenderDoc、PIX、Nsight、厂商计数器）；瓶颈定位流程（先分层再下钻）；优化
  杠杆库（合批、实例化、剔除、LOD、图集、mip、压缩、降采样、半精度、异步）；
  显存管理（常驻 vs transient、流送、预算）；回归防护（基线、自动截图对比）。
- 熟练掌握标准：给定卡帧场景能在工具链内定位到 pass 级根因；一切性能表述
  自带测量口径。

### 16. DCC 与资产管线（要求 L2–L3）
- 核心节点：DCC 工具族各自擅长面（Houdini/Blender/Maya/Substance/ZBrush）；
  交换格式边界与坑（FBX/glTF/USD/Alembic/EXR/VDB/PLY）；PBR 贴图规范（金属度
  流程与高光流程）；texel density、UV 与图集规范；烘焙链（法线、AO、曲率、
  厚度、位移）；命名、目录与版本规范；资产自动化（批处理、校验器、引用修复）。
- 熟练掌握标准：设计一条 DCC → 引擎的可重复资产链并含校验环节；诊断法线烘焙
  常见瑕疵（接缝、波浪、像素化）并给出修法。

### 17. 美术基础与审美协作（要求 L1–L2）
- 核心节点：色彩构成（明度、饱和度、对比）；构图与视觉引导；灯光艺术（三点
  打光、环境氛围、时间与天气）；风格化美术体系特征（三渲二、水彩、油画、像素
  等流派）；reference 收集与拆解方法；镜头语言基础；与美术沟通的技术词汇表。
- 熟练掌握标准：能把美术需求翻译成可执行的渲染/材质技术指标，并反向解释技术
  限制对画面的影响。

### 18. 工程协作与工具开发（要求 L2–L3）
- 核心节点：版本控制（Git/Perforce 语义、二进制资产锁）；CI 与自动化构建概念；
  脚本（Python/Shell）与数据序列化；工具设计原则（可回读、防误操作、失败
  可诊断）；文档与交接习惯；AI 辅助工具链概念（自动化 agent 的能力边界与
  校验必要性）。
- 熟练掌握标准：交付的工具他人可用——有输入校验、失败有明确报错、关键操作
  可回读可回滚。

## 五、跨域主干边（知识图谱的「边」）

以下概念贯穿多个域，是知识体系内聚的骨架，也是面试串联话题的天然线索：

1. **Beer-Lambert / 光程**：体积渲染 ↔ 云与雾 ↔ 体积化 splatting ↔ 神经蒸馏
   的 teacher 渲染 ↔ 体积光照烘焙。
2. **前缀和 / 排序 / 紧凑化**：GPU 剔除 ↔ 粒子分桶 ↔ splatting 光栅化 ↔
   等值面流压缩 ↔ 一切「先统计再写紧凑数组」的 GPU 模式。
3. **SDF**：表面重建 ↔ 体积空域裁剪 ↔ 特殊阴影（脸部/毛发）↔ 程序化建模
   ↔ 文本渲染。
4. **空间网格 / 哈希邻域**：流体模拟 ↔ 群体模拟 ↔ 粒子重建 ↔ 探针放置与
   光照缓存。
5. **噪声与域扭曲**：体积造型 ↔ 材质细节 ↔ 地形 ↔ 粒子扰动 ↔ 溶解/侵蚀类
   材质效果。
6. **投影与顺序敏感混合**：半透明排序 ↔ OIT ↔ splatting ↔ 屏幕空间粒子重建。
7. **局部性与层级数据**：GPU 内存层级 ↔ mip 与纹理流送 ↔ VDB 树 ↔ SVT 分页
   ↔ 虚拟纹理——同一原理在不同尺度的复现。
8. **测量口径与固定上下文**：一切性能与质量主张的公共校验层，适用于所有域。

## 使用方式

1. 以各域「熟练掌握标准」逐条自评当前深度（L1–L4），低于要求的回
   `TECH-STACK-REVIEW-CARDS.md` 补对应卡片。
2. 「五、跨域主干边」用于串联演练：随机抽一条，要求数分钟内把贯穿的域各讲
   一句并落到可验证的事实。
3. 本文件不做个人证据判定；自评结果、证据等级与盲区处置在复习卡与正本维护。
4. 域的增删与「熟练掌握标准」的调整属项目级决策，先记 LOG 再改本文件。
