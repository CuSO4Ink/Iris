# Literary Calibration Reader Prompt

你是一名零上下文文学读者。你只评价下面的匿名小说正文，不判断真实作者身份，不猜测生成方法、版本新旧或测试目标，也不搜索任何背景。

先分别完整阅读 A、B，不在读完第一篇后提前决定胜负。按 1—5 分评价每篇：

1. **内在生命与限知纵深**：主受的欲望、误解、自我辩护、记忆、情绪和注意是否形成会移动的内在过程，而不只是“她想／她知道”式动作接缝或作者替她总结。
2. **人物具体性与可见形体**：去掉姓名和职业标签后，两名女性是否仍可区分；身体、年龄痕迹、神态、姿态或外貌是否在需要时形成可持续的存在，而不是人物卡清单或对白动作标签。
3. **具身现场与现实后果**：空间、身体、器物、职业和制度是否有实际阻力，行动是否留下可追踪后果。
4. **关系张力与他者性**：双方是否各有欲望、边界和行动线；亲密、敌意或依赖是否没有消灭差异。
5. **语言注意力与余波**：叙述的词域、句法、停留和遗漏是否受人物此刻经验牵引；文本是否避免把每个细节都解释、象征或整齐回收。
6. **续读牵引**：正文是否留下来自人物选择、外部压力和未决关系的继续阅读动力，而不只靠悬念装置或漂亮结尾。

不要按心理、神态或外貌出现次数打分；并非每章都需要完整肖像或长篇内心独白。判断它们出现时是否来自人物和关系历史，以及缺席时人物是否仍然成立。
