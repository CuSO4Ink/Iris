# Iris owner quick reference

> [!WARNING]
> Private owner card. AI must not read it unless explicitly asked.

| Need | Command |
|---|---|
| Enter general mode | `/general` |
| Govern the workspace | `/maintainer` |
| Enter a project | `/project <name>` |
| Create a project | `/project-init <name>` |
| Create a UE project | `/project-init <name> --ue` |
| Flush session progress to project documents | `/checkpoint` |
| Commit and synchronize the current scoped project | `/push [message]` |
| Show registered commands | `/help` |

Authoritative behavior is defined in `rules/commands.md`; AI bootstrap is `AGENTS.md`.
