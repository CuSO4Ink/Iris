# Iris Talent Progression

为当前 RimWorld 1.6 + Vanilla Skills Expanded 配置制作的本地玩法 MOD。已有角色不重算，只处理新生成成年人的初始技能。旧存档可加入；首次安装或代码更新需要重启。设置菜单中的参数改动影响后续生成，不需要重启。

## 默认分布

- 普通型约45%、均衡型25%、专才型30%。保留本体先生成的能力排序作为职业方向，加少量随机变化。
- 早期普通主项1–3，均衡型几个主项1–3；专才主项4–6，其他多数0–1。存在少数额外高两级的专才。
- 发展充分后普通主项4–6；专才主项11–13，罕见者最高14。总技能预算限制全能人物。
- 专才主项可能出现狂热、恃才或少量偏长；普通、均衡型主要使用好奇。热情概率不随发展提高。
- 继承特性强制热情、基因热情修正；这些约束与保留战斗项属于预算之外的明确例外。

## 殖民地发展

发展分数0–1，由存续时间20%、已完成研究的基础研究点总量45%、玩家家园建筑财富35%组成。三个分项分别在180日、60000研究点、150000建筑财富达到上限。物品和人物财富不参与，避免拾到贵重装备直接抬高人才水平。

约每2500游戏tick更新一次，用3游戏日时间尺度平滑升降。旧存档第一次读取按已有发展状态初始化。没有玩家家园（例如初次生成世界）使用早期分布。跨地图以所有玩家家园的建筑财富合计计算；不代表已验证稳定生产、食物或医疗服务能力。

仅保存一个游戏级发展分数与更新时间。没有按人物遍历改写旧技能；既有世界人物后来来访或被招募仍保持原样。关闭MOD不会撤销已经生成的技能值。

## 保护范围

- 不调整开局选择页面的PlayerStarter人物、未成年人、派系领袖、指定贵族头衔人物及特殊CreepJoiner。
- 默认保留非玩家战斗职业原有射击、格斗和对应热情，避免削弱袭击主战力。因此可俘虏的战斗人员也可能有较高战斗技能。
- 额外特殊人物可以在设置填写PawnKind defName排除名单。没有凭名字猜测并排除所有MOD剧情人物。
- 不修改学习速度、Endless Growth上限、装备、种族、基因、特性、工作限制或450%袭击倍率。

## 设置

MOD设置 → **Iris 人才成长**：开关、保留战斗项、新人等级强度（默认1）、专才比例（默认30%）、发展影响（默认1）、额外排除名单。调整只影响下一批新生成人物。

## 验证与限制

编译通过；用同一TalentPolicy代码在游戏外抽样60000次。发展0/0.5/1时，最高技能平均3.31/5.32/7.52，总等级平均10.34/19.02/28.24；每阶段20000人中专才5995人、偏长123人。验证等级范围、整体预算、热情数量及相同种子的可重现性。

核对了本机PawnGenerator.GenerateSkills入口。补丁在该方法后处理，包括VSE替代本体生成的情况。其他MOD如果在更外层生成回调再次改技能，仍可能覆盖结果，需结合实际新人日志和界面核验。遵照用户要求，没有启动独立游戏测试，不将抽样测试等同于完整运行兼容性验收。

Source包含代码；构建输出在Assemblies，临时编译文件在仓库tmp/rimworld/talent-build。

维护补充：明确设置最低总技能/最低最高技能的PawnKind也排除初始压缩，保留生成硬性约束。
