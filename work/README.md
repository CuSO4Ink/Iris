# work — active projects

Only projects with current execution or governance belong here. Each project requires
`AI-BRIEF.md`; add `BACKLOG.md` and `LOG.md` only while they have work or durable history.

- UE projects use `/project-init <name> --ue` and keep the UEAgent-first block at the top.
- Durable project source and final evidence stay inside the project directory.
- Environments, runs, screenshots, generated evidence, and one-off scripts go to
  `tmp/<project-or-task>/`.
- Waiting-without-near-term-work, rejected, or closed projects move to `archive/`.
